## প্রোজেক্ট সম্পর্কে

UniJoy-macOS তৈরি করা হয়েছে একটাই উদ্দেশ্যে — ম্যাকে বাংলা টাইপিং যেন ঝামেলামুক্ত হয়। এটি কোনো থার্ড-পার্টি ইনপুট ইঞ্জিন বা ব্যাকগ্রাউন্ড সার্ভিসের উপর নির্ভর করে না। সরাসরি macOS-এর নিজস্ব Input Source মেকানিজম ব্যবহার করে কাজ করে, তাই সিস্টেমের যেকোনো অ্যাপে এটি স্বাভাবিকভাবে চলে।

অ্যাপটির সাথে একটি পূর্ণাঙ্গ কম্প্যানিয়ন অ্যাপ দেওয়া হয়েছে, যেখানে কীবোর্ড লেআউট দেখা, টাইপিং প্র্যাকটিস করা এবং যুক্তবর্ণ খুঁজে পাওয়ার ব্যবস্থা আছে — সব একটি জায়গা থেকে।


## কেন UniJoy ব্যবহার করবেন

- সিস্টেম-লেভেলে কাজ করে বলে আলাদা কোনো ইনপুট মেথড এডিটর চালু রাখার দরকার হয় না
- ম্যাকের ডার্ক মোডের সাথে মিলিয়ে ডিজাইন করা পরিচ্ছন্ন ইন্টারফেস
- অ্যাপের ভেতরে ইন্টারেক্টিভ কীবোর্ড ভিউ আছে, যেখানে প্রতিটি কী-তে কী লেখা আছে তা দেখা যায়
- বিল্ট-ইন টাইপিং টেস্ট দিয়ে নিজের বাংলা টাইপিং স্পিড যাচাই করা যায়
- ক্যাটাগরি ও সার্চ সুবিধা সহ একটি বিশাল যুক্তবর্ণ চার্ট অন্তর্ভুক্ত
- সম্পূর্ণ অফলাইনে কাজ করে, কোনো ধরনের ডেটা সংগ্রহ বা ইন্টারনেট কানেকশন লাগে না
- Intel ও Apple Silicon — উভয় আর্কিটেকচার সাপোর্ট করে (Universal Binary)

## ইনস্টলেশন

UniJoy ইনস্টল করা বেশ সোজা। নিচের ধাপগুলো অনুসরণ করলেই হবে।

### ধাপ ১ — ইনস্টলার ডাউনলোড

GitHub-এর [Releases](https://github.com/nuxrif/UniJoy-macOS/releases/latest) পেজ থেকে সবশেষ ভার্সনের **UniJoy-Installer.pkg** ফাইলটি ডাউনলোড করুন।

### ধাপ ২ — ইনস্টলার চালানো

ডাউনলোড শেষ হলে `.pkg` ফাইলটিতে ডাবল-ক্লিক করুন। macOS যদি সিকিউরিটি সংক্রান্ত কোনো সতর্কবার্তা দেখায়, তাহলে ফাইলটির উপর রাইট-ক্লিক করে **Open** অপশনটি সিলেক্ট করুন — এরপর স্বাভাবিকভাবে ইনস্টল হয়ে যাবে।

### ধাপ ৩ — অ্যাপ চালু করা

ইনস্টলের পর **Launchpad** অথবা **Applications** ফোল্ডার থেকে UniJoy অ্যাপটি খুলুন।

### ধাপ ৪ — কীবোর্ড লেআউট ইনস্টল

অ্যাপ খোলার পর ভেতরে **"ইনস্টল করুন"** বাটন পাবেন। এটিতে ক্লিক করলেই কীবোর্ড লেআউটটি সিস্টেমে যুক্ত হয়ে যাবে। পুরো প্রক্রিয়াটি ৩ থেকে ৫ সেকেন্ডের মধ্যে শেষ হয় এবং ম্যাক রিস্টার্ট দেওয়ার কোনো প্রয়োজন নেই।

### ধাপ ৫ — কীবোর্ড সুইচ করা

ইনস্টল হয়ে গেলে মেনু বারের ডানদিকে থাকা কীবোর্ড আইকনে ক্লিক করে UniJoy সিলেক্ট করুন। শর্টকাট হিসেবে `Control + Space` অথবা `Globe` বাটন ব্যবহার করতে পারেন।

---

### কীবোর্ড যদি স্বয়ংক্রিয়ভাবে তালিকায় না আসে

কিছু ক্ষেত্রে কীবোর্ড লেআউট ম্যানুয়ালি যুক্ত করতে হতে পারে। সেক্ষেত্রে নিচের ধাপগুলো অনুসরণ করুন:

1. **System Settings** খুলুন এবং বাম পাশ থেকে **Keyboard** অপশনে যান
2. **Input Sources** সেকশনের পাশে থাকা **Edit** বাটনে ক্লিক করুন
3. উইন্ডোর নিচে বাম কোণায় **+** (Add) বাটনটি চাপুন
4. বাম পাশের ভাষা তালিকায় স্ক্রল করে নিচে নামুন এবং **Others** সিলেক্ট করুন
5. ডান পাশে **UniJoy** দেখতে পাবেন — সেটি সিলেক্ট করে **Add** চাপুন

এরপর মেনু বার থেকে কীবোর্ড পাল্টে UniJoy ব্যবহার করা যাবে।

## সোর্স কোড থেকে বিল্ড

নিজে সোর্স কোড থেকে বিল্ড করতে চাইলে আপনার ম্যাকে Xcode অথবা Xcode Command Line Tools ইনস্টল থাকতে হবে। এরপর টার্মিনালে নিচের কমান্ডগুলো চালান:

```bash
# রিপোজিটরি ক্লোন
git clone https://github.com/nuxrif/UniJoy-macOS.git
cd UniJoy-macOS/UniJoyApp

# অ্যাপ বিল্ড
bash build.sh

# বিল্ড হওয়া অ্যাপ চালানো
open build/UniJoy.app
```

আপনি চাইলে ইনস্টলার প্যাকেজও তৈরি করতে পারেন:

```bash
# PKG ইনস্টলার তৈরি
bash create_pkg.sh

# DMG ইমেজ তৈরি
bash create_dmg.sh
```

### প্রোজেক্ট স্ট্রাকচার

```
UniJoy-macOS/
    UniJoyApp/
        Sources/          -- সমস্ত Swift সোর্স ফাইল
        Resources/        -- অ্যাপ আইকন ও অন্যান্য রিসোর্স
        build.sh          -- অ্যাপ বিল্ড স্ক্রিপ্ট
        create_pkg.sh     -- PKG ইনস্টলার তৈরির স্ক্রিপ্ট
        create_dmg.sh     -- DMG ইমেজ তৈরির স্ক্রিপ্ট
    UniJoyLayout.keylayout -- কীবোর্ড লেআউট ফাইল
    assets/               -- স্ক্রিনশট ও ডকুমেন্টেশন ফাইল
```
